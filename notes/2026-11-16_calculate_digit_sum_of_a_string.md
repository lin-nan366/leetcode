# 2243. Calculate Digit Sum of a String：分组求和与字符串模拟

题目：[计算字符串的数字和](https://leetcode.cn/problems/calculate-digit-sum-of-a-string/)

代码：[2243_calculate_digit_sum_of_a_string.py](../simulation/2243_calculate_digit_sum_of_a_string.py)

## 1. 这段代码在模拟什么

输入是只包含数字字符的字符串 `s` 和正整数 `k`。题目保证 `1 <= len(s) <= 100`、`2 <= k <= 100`。

只要当前字符串长度大于 `k`，就执行一整轮：

```text
每 k 个字符分组 → 每组逐位求和 → 把各组的和转为字符串并按原顺序拼接
```

最后一组可以不足 `k` 个字符。完成一轮后，用新字符串继续判断，直到长度不超过 `k`。
返回值是字符串。

这是一道模拟题，主要工作是准确实现分组、转换和多轮更新。
各组分别求和后还要拼接，不能把全部字符一次性求和来代替题目操作。

## 2. 变量与循环的职责

| 变量或语句 | 含义 |
| --- | --- |
| `s` | 当前这一轮要处理的字符串，整轮结束后更新 |
| `n` | 初始字符串长度，只用于开头的提前返回 |
| `k` | 每组最多包含的字符数量，也是停止时的长度上限 |
| `t` | 本轮各组计算结果组成的字符串列表 |
| `i` | 当前组的起始下标 |
| `total` | 当前组各位数字之和，是整数 |
| `while len(s) > k` | 决定是否需要再处理一轮 |
| `for i in range(...)` | 在同一轮中依次处理所有组 |

`t = []` 放在 `while` 内、`for` 外：每轮创建一个新列表，同一轮的各组结果追加到同一个列表中。

## 3. range 怎样实现每 k 个字符一组

```python
for i in range(0, len(s), k):
```

`range(起点, 不包含的终点, 步长)` 从下标 `0` 开始，每次增加 `k`。
例如 `s = "11111222223"`，长度为 `11`，`k = 3`，那么 `i` 依次取：

```text
0、3、6、9
```

组内字符通过切片取得：

```python
s[i : i + k]
```

切片左闭右开，包含下标 `i`，不包含 `i + k`。

| i | 切片 | 取出的组 |
| --- | --- | --- |
| 0 | `s[0:3]` | `"111"` |
| 3 | `s[3:6]` | `"112"` |
| 6 | `s[6:9]` | `"222"` |
| 9 | `s[9:12]` | `"23"` |

最后一个结束下标超过字符串长度时，Python 切片会在字符串末尾停止，不会因此越界。
各组没有重叠，且恰好覆盖本轮字符串的所有字符。

## 4. sum(map(int, ...)) 怎样计算数字和

```python
total = sum(map(int, s[i : i + k]))
```

以当前组 `"112"` 为例：

```text
切片得到字符串："112"
逐个读取字符：  '1'、'1'、'2'
int 转成整数： 1、1、2
sum 累加：    1 + 1 + 2 = 4
```

`map(int, group)` 将 `int` 应用于组内的每个字符。
它提供的是迭代器，`sum` 会逐个取出转换后的数字并累加。

为了观察转换结果，可以临时写：

```python
list(map(int, "112"))  # [1, 1, 2]
```

主代码直接交给 `sum` 消费，不需要额外创建这个整数列表。

`int("346")` 得到整数 `346`；逐位转换后求和得到的是 `3 + 4 + 6 = 13`，本题需要后者。

## 5. append、str 和 join 分别做什么

```python
t.append(str(total))
```

`total` 是整数，先用 `str` 转成字符串，再追加到列表末尾。
例如各组的数字和为 `3、4、6、5`，处理结束后：

```python
t = ["3", "4", "6", "5"]
```

然后执行：

```python
s = "".join(t)
```

空字符串是分隔符，表示把各项直接连接，不插入其他字符：

```text
"3" + "4" + "6" + "5" → "3465"
```

`join` 要求各项都是字符串，因此前面的 `str(total)` 有实际作用。
如果组和是两位数，例如 `13`，应当保留字符串 `"13"` 参与拼接。
`["13", "5"]` 拼成的是 `"135"`，不是把两个组和再相加得到 `18`。

## 6. 完整追踪两轮操作

输入：

```python
s = "11111222223"
k = 3
```

第一轮：

| 分组 | 数字和 | 加入 t 的字符串 |
| --- | --- | --- |
| `"111"` | 3 | `"3"` |
| `"112"` | 4 | `"4"` |
| `"222"` | 6 | `"6"` |
| `"23"` | 5 | `"5"` |

拼接后 `s = "3465"`。长度为 `4`，仍大于 `k = 3`，需要继续。

第二轮重新创建 `t = []`：

| 分组 | 数字和 | 加入 t 的字符串 |
| --- | --- | --- |
| `"346"` | 13 | `"13"` |
| `"5"` | 5 | `"5"` |

拼接后 `s = "135"`。长度为 `3`，满足 `len(s) <= k`，循环结束，返回 `"135"`。

## 7. 缩进、边界与初始判断

`s = "".join(t)` 必须在 `for` 循环外、`while` 循环内。
这样同一轮的所有切片都来自旧字符串，处理完成后才统一切换到新字符串。

截图中的开头是：

```python
n = len(s)
if n < k:
    return s
else:
    while len(s) > k:
        # 分组处理
        ...
```

- 初始长度小于 `k`：提前返回原字符串。
- 初始长度等于 `k`：进入 `else`，但 `while` 条件不成立，仍返回原字符串。
- 初始长度大于 `k`：进入模拟，完成所有必要轮次后返回。

因此原代码边界正确。初始的 `n` 和外层 `if/else` 也可以省去，直接执行 `while`，最后统一返回。
主代码保留截图结构，方便对照。

循环条件读取的是更新后的 `len(s)`。不能把它直接改成一直不更新的 `while n > k`，否则初始长度超过 `k` 时可能无法退出。

## 8. 每轮不一定立刻变短，但最终会结束

组和可能有两位甚至三位，所以不能认为“每组永远只变成一个字符”。
例如：

```text
s = "9999", k = 2
第一轮："99"、"99" → "18"、"18" → "1818"，长度仍为 4
第二轮："18"、"18" → "9"、"9" → "99"，长度变为 2，停止
```

对一组数字逐位相加后，结果的位数不会超过该组原来的位数，所以整轮的字符串长度不会增加。
如果一轮长度没有减少，至少有一组产生了多位数；把这个组和写成十进制后，它的各位数字之和会严格小于原来的组和。
因此整串的各位数字之和会减少。

也就是说，每轮至少让“字符串长度”或“各位数字之和”中的一项减少，而两项都不会增加，且都是非负整数。
结合题目保证 `k >= 2`，循环最终会结束。

## 9. 完整代码

```python
class Solution:
    def digitSum(self, s: str, k: int) -> str:
        n = len(s)
        if n < k:
            return s
        else:
            while len(s) > k:
                t = []
                for i in range(0, len(s), k):
                    total = sum(map(int, s[i : i + k]))
                    t.append(str(total))
                s = "".join(t)
        return s
```

## 10. 复杂度与易错点

设原始长度为 `n`，执行模拟的轮数为 `T`，每轮开始时的长度依次为 `m₀、m₁、...`。
一轮中的切片、逐位转换求和与结果拼接，合计耗时与该轮字符串长度成正比。

- 总时间可写为 `O(1 + m₀ + m₁ + ...)`；由于每轮长度不超过原始长度，也可以用 `O(1 + nT)` 表示上界。
- 初始长度不超过 `k` 时，不执行模拟，直接返回，耗时 `O(1)`。
- 列表 `t`、组内切片与新字符串所需的额外空间合计为 `O(n)`。

Python 字符串不可变，`s = ...` 会让变量指向新字符串，不会原地修改旧字符串。

复习时注意：

- `range` 的第三个参数是步长，控制每组起点相隔 `k`。
- 切片右端不包含；最后一组不足 `k` 个字符仍然需要处理。
- `map(int, group)` 转换每一个字符，不能用 `int(group)` 代替。
- `t` 每轮重新建立，`s` 每轮处理完所有组后统一替换。
- 组和要转为字符串，再交给 `join` 拼接。
- 返回字符串，保留拼接结果中的零。例如全零示例应得到 `"000"`，不能转成整数 `0` 后再返回。
- 长度等于 `k` 就应停止，不再额外处理一轮。

| 输入 s | k | 期望输出 | 检查重点 |
| --- | --- | --- | --- |
| `"11111222223"` | 3 | `"135"` | 多轮、最后一组不足 k、多位数组和 |
| `"00000000"` | 3 | `"000"` | 保留各组结果中的零 |
| `"9999"` | 2 | `"99"` | 第一轮长度没有减少 |
| `"999"` | 2 | `"99"` | 不足一组的尾部 |
| `"123"` | 3 | `"123"` | 长度恰好等于 k |
| `"12"` | 3 | `"12"` | 初始长度小于 k |
| `"9"` | 2 | `"9"` | 最小输入长度 |
| `"12345"` | 3 | `"69"` | 两组分别求和后拼接 |
| `"999999"` | 3 | `"117"` | 多位数组和继续参加下一轮 |
