# 238. Product of Array Except Self：复用答案数组与滚动右侧乘积

题目：[除自身以外数组的乘积](https://leetcode.cn/problems/product-of-array-except-self/)

代码：[0238_product_of_array_except_self.py](../array_algorithms/0238_product_of_array_except_self.py)

## 1. 题目要求与思路入口

返回数组 `ans`，其中 `ans[i]` 是 `nums` 中除了下标 `i` 以外所有元素的乘积。
排除的是当前位置，不是排除所有与 `nums[i]` 相等的元素。
例如 `[2, 2, 3]` 的答案是 `[6, 6, 4]`，前两个位置都仍要乘上另一个 `2`。

限制条件：

- 数组长度为 `2～10⁵`，可能包含零、负数和重复值。
- 不使用除法，要求 `O(n)` 时间。
- 进阶要求 `O(1)` 额外空间，明确不计输出数组所占空间。

如果每求一个答案都重新遍历其余元素，最坏需要 `O(n²)` 时间。
可以观察到，相邻位置需要的乘积有大量重叠，所以应当复用已经计算过的结果。

## 2. 把“除自身以外”拆成左右两部分

对于下标 `i`，其余元素自然分为两段：

```text
左侧：nums[0] ... nums[i - 1]
自身：nums[i]
右侧：nums[i + 1] ... nums[n - 1]
```

因此：

```text
ans[i] = 左侧全部元素的乘积 × 右侧全部元素的乘积
```

两段都不包含当前位置，所以相乘后恰好排除自身。
边界上的空乘积定义为 `1`：第一个元素没有左侧元素，最后一个元素没有右侧元素。
`1` 不会改变另一侧的乘积，因此初始化使用 `1`。

直接实现时可以准备独立的左侧积、右侧积数组，但这会使用 `O(n)` 辅助空间。
本次实现把左侧积直接存入答案数组，并用一个变量累计右侧积。

这里计算的是前缀积、后缀积；省掉的是独立的辅助数组，仍然使用左右乘积组合的思想。

## 3. 第一轮：把左侧乘积存进答案数组

初始化：

```python
ans = [1] * n
```

`ans[0] = 1`，表示第一个位置左侧没有元素。
对于之后的位置：

```python
ans[i] = ans[i - 1] * nums[i - 1]
```

`ans[i - 1]` 已经保存了 `nums[0]～nums[i - 2]` 的乘积，
再乘上 `nums[i - 1]`，就得到了当前位置左侧全部元素的乘积。

以 `[1, 2, 3, 4]` 为例：

| 下标 i | 左侧元素 | 写入 ans[i] 的值 |
| --- | --- | --- |
| 0 | 空 | 1 |
| 1 | `[1]` | 1 |
| 2 | `[1, 2]` | 2 |
| 3 | `[1, 2, 3]` | 6 |

第一轮结束后：

```text
nums = [1, 2, 3, 4]
ans  = [1, 1, 2, 6]
```

此时 `ans` 还只是左侧乘积，尚未得到最终答案。

## 4. 第二轮：用 right 累计右侧乘积

从右向左遍历，让变量 `right` 在每轮开始时表示当前下标右侧全部元素的乘积。

最右侧没有元素，所以从 `right = 1` 开始。
每轮按这个顺序执行：

```python
ans[i] *= right
right *= nums[i]
```

第一行组合当前左右两侧乘积，得到 `ans[i]` 的最终值。
第二行把当前位置加入 `right`，因为对于下一轮的下标 `i - 1`，`nums[i]` 已经属于右侧元素。

继续使用 `[1, 2, 3, 4]`：

| 下标 i | 原有左侧积 ans[i] | 本轮开始的 right | 最终 ans[i] | 更新后的 right |
| --- | --- | --- | --- | --- |
| 3 | 6 | 1 | 6 | 4 |
| 2 | 2 | 4 | 8 | 12 |
| 1 | 1 | 12 | 12 | 24 |
| 0 | 1 | 24 | 24 | 24 |

最终得到：

```text
ans = [24, 12, 8, 6]
```

第二轮不能先把当前元素乘进 `right`，否则计算 `ans[i]` 时就会包含自身。
例如处理下标 `3` 时，若先把 `right` 更新成 `4`，就会错误地得到 `6 × 4 = 24`，而正确答案是 `6`。

## 5. 完整代码

```python
class Solution:
    def productExceptSelf(self, nums: list[int]) -> list[int]:
        n = len(nums)
        ans = [1] * n

        for i in range(1, n):
            ans[i] = ans[i - 1] * nums[i - 1]

        right = 1
        for i in range(n - 1, -1, -1):
            ans[i] *= right
            right *= nums[i]

        return ans
```

## 6. 为什么这个过程正确

第一轮的含义：`ans[i]` 始终是严格位于 `i` 左侧的元素乘积。

- 起点 `ans[0] = 1` 正确表示空乘积。
- 从 `ans[i - 1]` 乘上 `nums[i - 1]`，刚好把左侧范围扩展到当前位置之前。

第二轮的循环不变式：每轮开始时，`right` 是严格位于当前 `i` 右侧的元素乘积。

- 从最右侧开始，`right = 1`，表示空乘积。
- 此时 `ans[i]` 仍保存第一轮的左侧积，因此 `ans[i] *= right` 恰好乘上左右两段，排除自身。
- 再执行 `right *= nums[i]`，就得到下一轮位置 `i - 1` 所需的右侧积。

倒序遍历不会影响尚未处理位置的左侧积，因此每个位置都能使用正确的左右信息。

## 7. 为什么有零和负数也不需要单独分支

这个过程始终做乘法，没有用除法，所以不会发生除零问题。

- 没有零时，左右两侧直接相乘。
- 恰好一个零时，其他位置的左右乘积中包含这个零，答案为 `0`；零所在位置排除了自身，会得到全部非零元素的乘积。
- 至少两个零时，每个位置排除自身之后仍然包含零，因此全部答案为 `0`。
- 负数的符号会随乘法自然计算，不需要额外处理。

例如：

```text
nums = [-1, 1, 0, -3, 3]
ans  = [0, 0, 9, 0, 0]
```

下标 `2` 的答案是 `(-1) × 1 × (-3) × 3 = 9`；其他位置的乘积都包含那个零。

## 8. 时间和空间复杂度

第一轮执行 `n - 1` 次，第二轮执行 `n` 次，两个循环依次执行，总时间为 `O(n)`。

返回的 `ans` 数组占 `O(n)` 空间，但题目明确不把输出数组计入额外空间。
除此之外，只保存 `n`、`i`、`right` 等固定数量的变量，所以额外空间为 `O(1)`。
若把输出也计算在内，整个实现分配的空间仍是 `O(n)`。

代码只读取 `nums`，不对其中元素赋值，输入数组保持不变。

| 实现方式 | 时间 | 额外空间，不计输出 |
| --- | --- | --- |
| 对每个位置重新相乘 | O(n²) | O(1) |
| 独立的左侧积、右侧积数组 | O(n) | O(n) |
| 答案数组保存左侧积，变量累计右侧积 | O(n) | O(1) |

## 9. 易错点与检查用例

- 排除的是当前下标，不是排除所有与当前元素相等的值。
- `ans` 和 `right` 初始化为 `1`，不能初始化为 `0`。
- 左侧积使用 `nums[i - 1]`，不能提前乘入 `nums[i]`。
- 右侧积使用倒序循环 `range(n - 1, -1, -1)`，最后一个 `-1` 是不包含的结束边界。
- 第二轮必须先更新答案，再更新 `right`，顺序不能交换。
- 省略后缀积数组不代表没有使用后缀积信息；`right` 就是当前需要的右侧积。
- 题目不允许除法，代码不使用 `/` 或 `//`。

| 输入 | 期望输出 | 检查重点 |
| --- | --- | --- |
| `[1, 2, 3, 4]` | `[24, 12, 8, 6]` | 基本流程 |
| `[-1, 1, 0, -3, 3]` | `[0, 0, 9, 0, 0]` | 一个零与负数 |
| `[2, 3]` | `[3, 2]` | 最小合法长度 |
| `[0, 4]` | `[4, 0]` | 边界上的零与空乘积 |
| `[0, 0]` | `[0, 0]` | 两个零 |
| `[2, 2, 3]` | `[6, 6, 4]` | 相等元素仍按不同位置参与计算 |
| `[-1, -2, -3]` | `[6, 3, 2]` | 全负数 |
| `[-1, 2, -3, 4]` | `[-24, 12, -8, 6]` | 正负数混合 |
