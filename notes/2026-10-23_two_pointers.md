## 42：每次相加的是哪一部分雨水

对于位置 i，水量等于左右最高柱子中较矮的高度减去当前柱高，两个最高值都包含当前柱子。
`pre_max` 是开头到 left 的最大高度，`suf_max` 是 right 到末尾的最大高度。

当 `pre_max <= suf_max` 时，left 右侧已经存在足够高的挡板，因此可以确定 left
这一列的水量为 `pre_max - height[left]`。另一种情况则结算 right 这一列。
每轮只计算一个位置，计算后移动相应指针，不会重复累计。

例如 `[2, 0, 3, 1, 2]` 中，下标 1 上方有 2 单位水，下标 3 上方有 1 单位水，总量为 3。

## 125：过滤字符与判断回文

```python
cleaned = "".join(ch.lower() for ch in s if ch.isalnum())
```

`isalnum()` 只判断字符是否属于字母或数字，返回布尔值；外层的 if 才负责筛选。
`lower()` 转成小写，空字符串作为 join 的分隔符，表示直接连接字符。
对于整个字符串，isalnum() 要求字符串非空且每个字符都合格。
实际的 isalnum() 支持 Unicode 字母和数字；英文题目中可以先把它理解为三个编码范围的判断。

清理后可以使用 `cleaned == cleaned[::-1]`，本次代码使用左右指针逐对比较。
全部是空格或标点时，清理结果为空，应返回 True。

## 2105：补水和浇水必须在同一次处理中完成

水不够时先补满，然后立即扣除当前植物的需水量、移动指针。
不能在 else 里只补水，把浇水推迟到下一轮，否则两人的进度会错开。
两端尚未相遇时，一轮中两人都应完成当前植物；中间一株由剩余水更多的人处理。

回归用例：`plants = [3, 2, 2, 1, 3]`，两人容量都是 4。
第一轮各剩 1；第二轮 Alice 补水并浇完后剩 2，Bob 浇完后剩 0。
中间需水 2，由 Alice 完成，所以只需补水 1 次。

## 16：距离和三数之和是不同的量

- `res` 保存历史最小距离，初始为 `float("inf")`。
- `ans` 保存产生这个距离的三数之和；发现 `abs(s - target) < res` 时两者一起更新。
- 和偏大时右指针左移，和偏小时左指针右移，等于 target 时可以直接返回。
- 最后的 return 必须在整个 for 循环外，不能只处理第一个固定位置就返回。

把比较写成 `res < abs(s - target)`，初始的无穷大永远不会被更新。
`nums = [0, 0, 0]`、`target = 1` 时，距离为 1，但应该返回三数之和 0。
`[-1, 2, 1, -4]`、target 为 1 时，最佳和为 2，需要继续枚举后面的固定位置。

## 15：找到答案后也必须前进，并按数值组合去重

当 s 为 0 时，如果只 append 而不移动指针，下一轮仍计算同一组三个数，
结果列表不断增长，最后超出内存限制。
记录后移动 j、k，再跳过与刚使用的值相同的元素；外层固定值重复时也跳过。
每次跳过重复值，都需要检查 `j < k`。

不能直接对输入数组去重，因为 `[-1, -1, 2]` 是合法答案。
题目要求不同数值组合只出现一次，所以 `[-2, 0, 0, 2, 2]` 只返回一个 `[-2, 0, 2]`。

## 611：固定最长边时，指针起点也必须配套改变

沿用截图里的变量：i 表示当前选定的最长边下标，`x = nums[i]`，
i 从 2 枚举到 n - 1，`j = 0`、`k = i - 1`。始终保持 `j < k < i`。

若 `nums[j] + nums[k] > x`，固定 k、i 后，j 到 k - 1 的每个下标都能做第三条边，
一次增加 `k - j` 个组合，再让 k 左移。
若不成立，当前 j 搭配范围内最大的 k 都不够，搭配更小值也不行，因此让 j 右移。

不能保留 `j = i + 1`、`k = n - 1` 却只改比较式，那时 x 仍是最短边。
例如 `[2, 2, 4]` 中，`4 + 2 > 2` 成立，但它并不能构成三角形，因为 `2 + 2 == 4`。

本题按不同下标计数，不需要像第 15 题那样去重。
`[2, 2, 3, 4]` 中，最长边为 3 时有 1 组，为 4 时有 2 组，总计 3。
