# 2026-11-02：160. 相交链表

[解题代码](../linked_list/0160_intersection_of_two_linked_lists.py)
采用截图中的双指针切换链表写法，时间 O(m + n)，额外空间 O(1)。

## 什么叫相交

相交是两个指针能访问到同一个节点对象。从这个节点开始，后续节点也共享。
两个独立创建、val 相等的节点不算相交，因此这里比较节点身份，使用 `is`。
题目保证无环，并要求函数结束后保留原来的节点值与连接。

```text
A: a1 -> a2 --------> c1 -> c2 -> c3 -> None
                     ^
B: b1 -> b2 -> b3 ----|
```

## 每一行在做什么

```python
p = headA
q = headB
while q is not p:
    q = q.next if q else headA
    p = p.next if p else headB
return q
```

- p 从 A 出发，走到 None 后从 B 的头节点继续。
- q 从 B 出发，走到 None 后从 A 的头节点继续。
- 每轮两者都更新一次，速度相同；顺序交换抵消了长度差。
- 两者指向同一节点时，返回这个节点；两者同时为 None 时，返回 None。
- 这里只重新绑定局部变量，没有修改任何节点的 next，也没有创建新节点。

## 示例中的完整移动过程

以下每一行表示一轮循环执行结束后的状态，初始状态记为第 0 轮。

| 轮次 | p | q |
| --- | --- | --- |
| 0 | a1 | b1 |
| 1 | a2 | b2 |
| 2 | c1 | b3 |
| 3 | c2 | c1 |
| 4 | c3 | c2 |
| 5 | None | c3 |
| 6 | b1 | None |
| 7 | b2 | a1 |
| 8 | b3 | a2 |
| 9 | c1 | c1，循环结束 |

注意，第 2 轮只有 p 到达 c1，不能立即返回，必须等到两者指向同一对象。

## 为什么能抵消长度差

设 A 独有部分长 a，B 独有部分长 b，共享部分长 c。
p 的路线是 A 独有部分、共享部分，再到 B 独有部分；
q 的路线是 B 独有部分、共享部分，再到 A 独有部分。

若 a 与 b 不同，切换后到达公共起点所需的循环次数分别是
`a + c + 1 + b` 和 `b + c + 1 + a`，两者相等。
这里的 1 对应从 None 切换到另一头节点的那次更新。
若 a 与 b 相同，第一次遍历时就能在公共起点相遇。

如果没有公共部分，两个指针最终会同时指向 None，循环正常退出。
无需提前统计长度，也不需要为访问过的节点建立集合。

## 易错点与测试

- 不能用 `p.val == q.val` 判断相交，同值节点可能是不同对象。
- 不能用 `while p and q` 代替身份比较，短链表到头时还需要切换，而不是停止。
- 在指针为 None 时切换；保留这个状态才能处理不相交的输入。
- 改变的是 p、q 的引用，不能用修改尾节点 next 的方式拼接链表。

测试真正构造共享尾部，检查返回节点身份，并核对输入节点的值与 next 均未改变。
覆盖不等长、头节点相同、只共享尾节点、同值但不相交、空链表等情况。
